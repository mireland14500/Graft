# Homepage photos

Put photos here with these exact names and they appear on the homepage automatically
(no code changes; restart `npm run dev` if one doesn't show):

| File | Where it shows |
|---|---|
| `hyrox.jpg` | Hero slideshow + Hyrox card |
| `crossfit.jpg` | Hero slideshow + CrossFit card |
| `powerlifting.jpg` | Hero slideshow + Powerlifting card |
| `running.jpg` | Running card |
| `bodybuilding.jpg` | Bodybuilding card |
| `coach.jpg` | "For coaches" section |

`.jpg`, `.jpeg`, `.webp`, `.png` and `.avif` all work. Landscape, at least 1600px wide, works best.
Only use photos you have the rights to (your own, or free-licence sites like Unsplash or Pexels).
